# IP Address Application (IPv4 / IPv6)

Mini-projet POO/Python + DevOps/DevNet — Cisco DevNet 4.9.4 Project Activity 3 : Social Coding (option 2).

Application Python orientée objet qui interroge des API REST publiques pour afficher
l'adresse IP publique (IPv4 et IPv6) de la machine, sa localisation approximative et son opérateur.
